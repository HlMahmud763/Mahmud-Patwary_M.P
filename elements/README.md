# Mahmud Patwary (MP) — Premium 3D Portfolio

A cinematic 3D animated portfolio in **3 plain files**:

```
index.html   ← all the content (text, links, images)
style.css    ← all the design (colours, layout, animations)
script.js    ← 3D scenes, scroll animations, menu, lightbox, form
```

No build step, no npm, no setup. Upload the 3 files and the site works.

---

## 🚀 Publish on GitHub Pages (2 minutes)

1. Open your repository on GitHub (for example `Mahmud-Patwary_M.P`).
2. Click **Add file → Upload files**.
3. Drag in **`index.html`, `style.css`, `script.js`** and replace the old files.
4. Click **Commit changes**.
5. Go to **Settings → Pages**.
6. **Source:** `Deploy from a branch` → **Branch:** `main` → folder `/ (root)` → **Save**.
7. Wait about 1 minute, then visit:
   `https://hlmahmud763.github.io/Mahmud-Patwary_M.P/`

> The 3 files must be in the **root** of the repo (not inside a folder).
> The file names must be exactly `index.html`, `style.css`, `script.js` in lowercase.

## ✏️ How to edit

Open `index.html` in any text editor (VS Code or Notepad):

- **Text:** find the words and change them.
- **Images:** change the `src="..."` link of any `<img>`.
- **Live websites:** look for `<!-- Live websites -->`.
- **Contact links:** look for `<!-- =============== CONTACT =============== -->`.

The photos load from your GitHub repo:
`https://raw.githubusercontent.com/HlMahmud763/Mahmud-Patwary_M.P/main/...`
Keep these image files in that repo: `MP-Profile-Photo.jpg`, `AllahuAkbar.jpg`, `Alhamdulillah.jpg`, `SubhanAllah.jpg`, `Astagfirullah.jpg`, `Sabr.jpg`, `Lailaha.jpg`, `Python_Certificate.jpg`, `WebDesign_certificate.jpg`, `GraphicDesign_certificate.jpg`.

## 💻 Preview on your computer

Double-clicking `index.html` may not run the animations, because browsers block scripts from local files.
To preview locally, use the **Live Server** extension in VS Code (right-click `index.html` → *Open with Live Server*).
On GitHub Pages everything works automatically.
